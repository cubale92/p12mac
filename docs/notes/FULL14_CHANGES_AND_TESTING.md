# P-12 FULL14 — Piano Roll usability beta

Built on FULL13. Visible Piano Roll Undo/Redo buttons with Ctrl+Z/Ctrl+Y, enabled/disabled indicators and backend history counts; undo/redo feedback; persistent teal marks on the piano-key rows that contain entered notes; gold selection coloring on the keyboard and note rectangles; selected pitches in a dedicated footer readout; automatic vertical reveal of selected notes when off screen; readable note names on narrower note rectangles.

This is a Windows **source package**, not a precompiled executable. Source syntax and regression checks only; MIDI hardware and native JUCE/VST audio runtime have not been tested on Windows. Keep existing FULL13 generic MIDI, Rossum, and native routing as-is.
