Key correction:
- SP-1200 internal event resolution is treated as 24 PPQN.
- A P-12 16th-note grid step therefore equals 6 native SP ticks.
- The packed timing byte stores tick modulo 64 multiplied by four.
- bit1-clear bytes are NOT junk: they are timing-only markers used to bridge 64-tick phase wraps.
- Equal/repeated phase values advance to the next 64-tick cycle.

Round-trip proof:
- Each real segment was decoded to absolute native ticks and then regenerated.
- Regenerated bytes were required to match the original segment byte-for-byte.
- Result: PASS — all segment streams regenerated exactly.
