P-12 v1.0 — ROSSUM SP-1200 MIX / SONG / TUNE ROUND-TRIP AUDIT — 2026-10-02

This build continues the existing P-12 v1.0 line. It does not replace the project with a new design.

DONE IN THIS PASS
- Rossum stored Mix 1-8 table is decoded from the native firmware-compatible 8 x 32-byte table.
- Mix byte is treated losslessly as: output channel bits 0-2, level bits 3-6, Tune-vs-Decay bit 7.
- All 5,632 stored-mix bytes across the supplied 22-file Rossum corpus decode -> encode byte-identically.
- SP MIX selector + SELECT (Setup 16 behavior) + STORE (Setup 15 behavior) added to the P-12 mixer.
- Selecting a stored mix restores per-pad level, output channel, and Tune-vs-Decay mode.
- Undefined Rossum mix slots (all FF) remain undefined; a fresh P-12 project creates Mix 1 and leaves Mix 2-8 undefined.
- Song D5..DC Select-Mix commands are decoded and applied at the correct sequence boundary during P-12 song playback.
- P-12 song steps remember the selected SP Mix. The exported Rossum song emits a Select-Mix token only when the mix changes.
- Mixer song display shows mix locks as e.g. 01[M1] -> 02[M2].
- SP output assignment 1-8 is editable in both mixer views and is used as a hardware-style choke group.
- SP Tune/Decay mode is editable in both mixer views.
- SP Decay amount is editable in both mixer views and is written as the per-hit native sequencer parameter when the pad is DECAYED.
- Imported native per-hit parameter bytes remain authoritative. P-12 no longer adds Tune AT on top of an imported event pitch (fixes double-pitch behavior).
- When auditioning an imported pad, P-12 infers a useful Tune AT / Decay value from that pad's most common recorded native event parameter. Exact sequence playback still uses each event's own stored value.
- Tune BF remains pre-sample and is baked into Rossum sample audio; Tune AT remains post-sample / sequencer state.

ROSSUM FORMAT FACTS USED
- Firmware 1.04 Define Mix copies byte 0 of each 10-byte live sound-state record into the selected 32-byte mix snapshot at RAM 7094.
- Select Mix copies those 32 bytes back into the live sound-state records.
- Firmware channel assignment edits bits 0-2 of that byte.
- Setup 18 Tune/Decay toggles bit 7 of that byte.
- The remaining bits 3-6 are the stored mix-level field.
- Pitch/Decay fader AMOUNTS used by recorded hits are carried by native sequencer event parameter bytes; they are not additional bytes inside the 32-byte stored mix snapshot.
