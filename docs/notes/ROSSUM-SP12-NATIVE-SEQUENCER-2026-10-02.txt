P-12 v1.0 — Rossum SP-1200 native .sp12 sequencer update
=========================================================

Goal
----
One .sp12 file carries the P-12/Rossum project: samples plus native segment
(sequencer) data and song data. Loading a Rossum .sp12 populates P-12's visible
sequencer. Exporting from P-12 writes the sequencer/song back into the same .sp12.

2026-10-02 codec correction
---------------------------
The previous experimental decoder treated the native timing base as 96 PPQN.
That was wrong by 4x. The SP-1200 timing unit used by the packed event stream is
24 PPQN (the manual's "1/96th note" clock unit = 96 divisions of a whole note).
Therefore one P-12 16th step is 6 native ticks.

The firmware/corpus also proves that bit1-clear event-stream bytes are timing
markers. They bridge the 6-bit phase counter across 64-tick wraps. Repeated equal
phase values are not duplicates: each one advances another 64 native ticks.

Validation
----------
22 native segments from 22 supplied real .sp12 files were decoded and regenerated.
All 22 segment byte streams regenerated byte-for-byte exactly, covering 1,481 hit
descriptors and 34 timing-only wrap markers.

Controlled examples:
- PLOKnoseq.sp12: empty 768-tick segment = 12 timing markers + end marker.
- PLOK        _(2).sp12: two D4 hits separated by 384 native ticks, with the
  expected timing markers between them.
- _0 K        _.sp12: 192-tick segment with four native events at 0/48/96/144.

Song foundation
---------------
Firmware-derived tables are used: 100 segment pointers and 100 song pointers.
Song data grows downward and has the Rossum seven-byte header. Simple P-12 song
chains are written into the same .sp12 file. If a native Rossum song is imported,
its tempo is applied to the referenced P-12 patterns, and unedited special song
command bytes are preserved for round-trip.

Hardware gate
-------------
Static/syntax checks and byte-exact corpus round-trip tests pass. The final proof
for newly-authored P-12 sequence/song data is loading the generated .sp12 on the
physical Rossum SP-1200. Do not discard the original Rossum project until that
hardware test passes.
