P-12 Rossum corpus audit — native Tune / Multi-Pitch / Multi-Level

Ground-truth firmware rules used:
- Factory Multi-Pitch bytes: 07 06 04 02 00 0F 0D 0B
- Signed 4-bit tune decode: 0..7 => +0..+7 semitones; 8..15 => -8..-1 semitones
- Therefore factory Multi-Pitch => +7,+6,+4,+2,0,-1,-3,-5 (monotonic descending)
- Factory Multi-Level bytes: 50 70 90 B0 C0 D0 E0 F0
- Event high nibble is level; increasing 5,7,9,B,C,D,E,F gives increasing level.
- A zero high nibble is treated as no explicit level override, not silence.

Key HAX correction:
- HAX active pads are A1, A2, A3, A7, A8. There is no active Bank D sound in HAX.
- HAX A7 code 0x0E is -2 semitones under the firmware encoding (old P-12 incorrectly made it -7).
- HAX A8 codes 0x06/0x03/0x04 are +6/+3/+4 semitones.

Key cross-project correction:
- RODE contains low nibble 0x0D, which is -3 semitones. Old P-12 7-code math made it -6: exactly a 3-semitone over-downshift.
- _LOK contains 0x0B/0x0D etc; signed-nibble decoding handles these without a project-specific offset.

P-12 changes in this build:
- Native Rossum Tune AT uses signed 4-bit semitone decoding/encoding.
- Native event high-nibble level is preserved in playback (Multi-Level / dynamics).
- Tune BF remains a separate pre-sample stage; import does not invent a Tune BF correction.
- Native event ticks, PPQ, Time Correct, swing and adaptive grid were not changed.
